# 个人主体小程序：能力限制 & 提审说明（SchoolShop）

> 给全员看。政策会变，**以微信公众平台当前后台提示与官方文档为准**。  
> **已决策**：不下线支付（本来就没有）；**已下线匿名树洞 / 漂流瓶**，降低安全审核风险。

---

## 1. 个人版影响（更新后）

你们不做微信支付 → 对个人主体很友好。

| 能力 / 场景 | 个人主体 | 对我们的影响 |
|-------------|----------|--------------|
| 微信支付 | 受限 | **无影响** |
| 课表 / 地图工具 / 签到 | 较友好 | 主打方向 |
| 资料积分兑换 | 中等 | 包装成学习工具，勿写成商城 |
| 代办悬赏（积分） | 中等 | 互助任务看板，勿写真钱跑腿 |
| 帖子 / 找搭子 | 有风险 | **必须内容安全 + 举报**；话术偏学习组队 |
| 匿名树洞 / 漂流瓶 | 极高风险 | **已从前端与接口规范移除** |

---

## 2. 提审别写「秋招 demo」

**短答：不建议，过审概率偏低。**

用产品叙事，例如：

> 面向在校学生的校园学习效率工具，提供课表查看、校园地点速查、学习打卡与校园互助任务看板等功能。不涉及真实资金支付与提现。

细节与自检清单见下文；后端安全备案见 `TECH-REQUIREMENTS.md` 第 4 节。

**勿写：** demo / 演示 / 面试 / 内部测试 / 可提现。

---

## 3. 提审前自检

- [ ] 主路径可走通；无树洞/漂流瓶入口  
- [ ] 备案与合法域名就绪  
- [ ] 隐私政策、用户协议可打开  
- [ ] 介绍定位「学习工具」  
- [ ] UGC（帖子/评论/找搭子）有内容安全  
- [ ] 提审备注可附测试账号  

---

## 4. 体验版也是选项

若只为秋招展示，**体验版分享**往往比硬闯正式版更划算；正式版则严格按工具向精简 + 安全要求执行。
