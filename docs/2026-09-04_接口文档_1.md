## 1. 变更摘要

v1.0 仅要求前端实现 `text_delta` + `done` + `error`。  
**v1.1 起后端会在爬虫检索完成后，额外推送结构化资源块**，前端需适配以下类型：

| 块类型 | v1.0 | v1.1 | 说明 |
|--------|------|------|------|
| `text_delta` | ✅ | ✅ | 文字摘要/进度，继续拼接 |
| `video` | — | ✅ **新增** | 可播放视频地址（m3u8/mp4） |
| `link` | 预留 | ✅ **启用** | 详情页/剧集页/普通链接 |
| `image` | 预留 | ✅ **启用** | 封面/海报图 |
| `done` | ✅ | ✅ | 流结束 |
| `error` | ✅ | ✅ | 流异常结束 |

> HTTP 路径、会话接口、SSE 帧格式**不变**，仍使用 `POST /api/v1/chat/stream`。

## 2. 前端必须做的适配

### 2.1 扩展 TypeScript 类型

在 `src/types/chat.ts` 中补充：

```typescript
export type StreamChunk =
  | { type: 'text_delta'; content: string }
  | {
      type: 'video'
      url: string
      title: string
      format?: 'm3u8' | 'mp4' | 'unknown'
      source_page?: string
      road_name?: string
    }
  | {
      type: 'link'
      url: string
      title: string
      description?: string
    }
  | {
      type: 'image'
      url: string
      alt?: string
    }
  | { type: 'done'; message_id: string; conversation_id: string }
  | { type: 'error'; code: string; message: string }
```

### 2.2 SSE 解析器

`src/utils/sse.ts` 中对 `event: chunk` 的 `data.type` 做分支处理，**不要**把所有 chunk 都当 `text_delta`。

### 2.3 聊天页渲染（`ChatPage.vue`）

建议按消息内资源分区渲染：

| 块类型 | 推荐 UI | 交互 |
|--------|---------|------|
| `text_delta` | 助手气泡正文 | 继续 `content += chunk.content` |
| `video` | 视频卡片 / 播放按钮 | 点击用播放器打开 `url`；`format=m3u8` 时需 HLS 支持 |
| `link` | 可点击标签/列表项 | 新窗口或内嵌 WebView 打开 |
| `image` | 缩略图 | `<img :src="url" :alt="alt" />`，注意跨域与 HTTPS |

### 2.4 消息数据结构建议

```typescript
interface AssistantMessage {
  id?: string
  role: 'assistant'
  content: string                 // 来自 text_delta 拼接
  videos: VideoChunk[]            // type=video
  links: LinkChunk[]              // type=link
  images: ImageChunk[]            // type=image
  streaming: boolean
}
```

收到 `done` 后 `streaming = false`，并写入 `message_id`。

## 3. 资源块详细定义

### 3.1 `video` — 视频资源（v1.1 新增）

爬虫从剧集页/播放页提取到的 **可直接播放或交给播放器解析** 的地址。

```json
{
  "type": "video",
  "url": "https://cdn.example.com/ep1/index.m3u8",
  "title": "第1集",
  "format": "m3u8",
  "source_page": "https://site.example.com/play/1",
  "road_name": "线路1"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `type` | `"video"` | ✅ | 固定值 |
| `url` | `string` | ✅ | 视频地址 |
| `title` | `string` | ✅ | 集标题 |
| `format` | `string` | ❌ | `m3u8` / `mp4` / `unknown` |
| `source_page` | `string` | ❌ | 来源剧集页 |
| `road_name` | `string` | ❌ | 播放线路名 |

**前端播放建议：**

- `format=m3u8`：使用 hls.js / 原生 HLS（Safari）/ 小程序 video 组件
- `format=mp4`：直接用 `<video src>` 或系统播放器
- 若播放器失败，可降级打开 `source_page` 或提示用户

---

### 3.2 `link` — 链接资源（v1.1 启用）

```json
{
  "type": "link",
  "url": "https://site.example.com/detail/123",
  "title": "葬送的芙莉莲",
  "description": "搜索结果"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `type` | `"link"` | 固定值 |
| `url` | `string` | 链接地址 |
| `title` | `string` | 展示标题 |
| `description` | `string` | 副标题，如「搜索结果」「线路1」 |

用途：详情页、剧集列表页、非直链资源入口。**与 `video` 区分：`link` 不一定是可播放直链。**

---

### 3.3 `image` — 图片资源（v1.1 启用）

```json
{
  "type": "image",
  "url": "https://cdn.example.com/poster.jpg",
  "alt": "葬送的芙莉莲"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `type` | `"image"` | 固定值 |
| `url` | `string` | 图片地址 |
| `alt` | `string` | 替代文本/标题 |

## 5. 前端消费伪代码

```typescript
function applyChunk(message: AssistantMessage, chunk: StreamChunk) {
  switch (chunk.type) {
    case 'text_delta':
      message.content += chunk.content
      break
    case 'video':
      message.videos.push(chunk)
      break
    case 'link':
      message.links.push(chunk)
      break
    case 'image':
      message.images.push(chunk)
      break
    case 'done':
      message.id = chunk.message_id
      message.streaming = false
      break
    case 'error':
      showError(chunk.code, chunk.message)
      message.streaming = false
      break
  }
}
```

## 7. 后端爬虫能力说明（供前端理解数据来源）

后端已支持两类 Kazumi 插件规则（站点配置在 `src/main/resources/plugins/`）：

| 模式 | 字段 | 说明 |
|------|------|------|
| XPath | 默认 | HTML 页面搜索 + 章节 XPath |
| API | `searchMode=api` / `chapterMode=api` | MacCMS 等 JSON API + JSONPath |

用户可在对话中指定站点：

- 插件名：`DM84`、`MacCMSDemo`
- 或站点 URL：`https://dmbus.cc/`

前端**无需**传站点参数给新接口；站点识别由 Agent 从自然语言解析。若后续需要显式选站，可再扩展请求体字段 `site`（当前未开放）。

## 8. 错误码（业务层，SSE `error` 事件）

| code | 前端建议 |
|------|----------|
| `CRAWL_FAILED` | Toast「未找到资源/站点不可用」，保留已收到的 text_delta |
| `AGENT_TIMEOUT` | 提示重试 |
| `AGENT_ERROR` | 通用错误提示 |
| `CONVERSATION_NOT_FOUND` | 清空 conversation_id 重新建会话 |
| `INVALID_REQUEST` | 检查 message 是否为空 |
